# AegisIQ Architecture Documentation

## Overview
AegisIQ's system architecture documentation is structured across the following specifications:

- **[System Architecture Specification](system-architecture.md)**: End-to-end component topology, data flows, and modular monolith package definitions.
- **[Architecture Decision Records (ADRs)](../adr/)**: Formal ADRs (ADR-001 through ADR-007) documenting key architectural choices, trade-offs, and consequences.
- **[STRIDE Threat Model](../security/threat-model.md)**: Security boundaries, trust domains, and threat countermeasures.
- **[Domain Model & Schema](../database/domain-model.md)**: Normalized relational database schema and entity specifications.
- **[Docker Deployment Strategy](../infrastructure/docker-strategy.md)**: Multi-stage container builds and container networking.
- **[Testing Strategy](../testing/testing-strategy.md)**: Automated test pyramid, benchmark metrics, and AI evaluation criteria.
