# AegisIQ Frontend (Security Operations Center)

## Overview
A high-density, professional React + TypeScript Single Page Application (SPA) built with Vite for security analysts and engineers.

## Architectural Tenets
- **Dark-First Ergonomics**: Designed for security operations centers (SOC) with curated contrast and typography.
- **Strict Type Safety**: Full TypeScript typing for all API contracts, DTOs, and state stores.
- **Zero Fluff**: Clean information density, attack-path visualization, and interactive AI investigation chat.

## Running Locally
```bash
npm install
npm run dev
```

## Running Tests
```bash
npm test
```
